# Rivet source register

Access date for every entry: **2026-10-30 (Asia/Singapore)**. Sources were read through public web research; no package, model, or application was installed or executed. This is an evidence register, not a dependency lockfile. Versions are the values displayed by the fetched pages, not selected Rivet dependencies or guarantees that a moving `latest` URL will remain unchanged. Recheck exact release artifacts, manifests, checksums, notices, advisories, and minimum supported Rust versions before acquisition.

**Evidence labels:** upstream documentation describes upstream behavior; repository/package metadata describes a particular snapshot; Rivet recommendations are inferences and remain proposals. An available documentation page alone does not prove active security support. Maintenance observations below are limited to visible releases, documentation, and explicit upstream notices; no maintainer responsiveness audit was performed. License observations are preliminary, not a transitive distribution clearance.
