# Roadmap

P1 Solo/adapters, P2 recovery/bounded lifecycle and P3 explicit hierarchies/model policies/local Mesh/Adaptive have bounded implementation evidence. The [latest audit](../planning/research/post-p3-verification.md) records partial requalification and publication gates.

P4 browser/Linux desktop qualification, optional Android testing, P5 official Unrivet mod integration, P6 managed assets/updates and P7 Linux release qualification remain future work. A chat-first hybrid UI and one global Command Center, workspace model C and reproducible recipe-first export are approved product decisions, with no implementation in this run. Resource Controller, memory, Recycle Bin and concurrent worktree details remain research proposals.

Useful pre-1.0 milestones precede mature Linux-only v1.0. macOS with real native inspection follows, then Windows. No dates or release are promised. No installer preset automatically acquires models or inference runtimes. Portable remains the recommended planned installation location; System is explicit opt-in.

See the [post-P3 handoff](../planning/POST_P3_HANDOFF.md) for risks, decisions and proposed bounded stages. New implementation needs explicit authorization.
